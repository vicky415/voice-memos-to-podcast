# iPhone / iPad handoff

Select the intended recording in Voice Memos → Share → Save to Files → a chosen iCloud Drive folder, such as Podcast Inbox. AirDrop is also suitable. Choose rendered/flattened audio if export options appear. Wait for full download on the publishing computer.

Optional share-sheet Shortcut recipe: create “Prepare podcast recording”, enable Show in Share Sheet for files/media, save input to Podcast Inbox with name review enabled, then show the saved filename. Invoke the installed skill in the agent with that exact path and episode metadata.

This is a recipe, not a signed installable `.shortcut`. The repository does not install an iOS app, folder watcher or remote server. Sharing to Files does not automatically launch Codex. A computer running the skill is required for its browser workflow; phone-only users can upload directly in Spotify for Creators. Do not place passwords or tokens in shared Shortcuts.
